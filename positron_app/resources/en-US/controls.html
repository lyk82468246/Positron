Input contract

The address bar uses a native EDIT control. Enter submits it and Escape restores the last committed address. Backspace remains the EDIT control's deletion key.

Native text controls

The following text, password and multiline fields are native WM6 EDIT children. Their value, focus and beforeinput/input/change path is connected to the Core document.




Native selections

Single and multiple SELECT controls use the WM6 COMBOBOX/LISTBOX controls. Selection changes are committed to the Core document and the Browser input/change bridge.



Native toggles

Checkboxes and radio buttons use native WM6 BUTTON children. Core keeps the checked state and radio-group rules; Browser receives trusted click, input and change events.
