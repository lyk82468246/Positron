Downloads

Enter an HTTP(S) link and select Download. The link is checked in the background; only a successful check opens the save dialog with its suggested file name and extension. If no valid name is available, enter one below and select Download again. Up to two tasks, one transfer and one link check. Maximum 32 MiB and two minutes per transfer. Existing files are never replaced. No resume or automatic opening.
