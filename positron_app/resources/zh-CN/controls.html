键盘和焦点

Tab 会在原生应用控件之间移动。当页面拥有焦点时，向上和向下方向键会访问这些链接，Enter 会激活当前链接。

向左和向右方向键水平滚动。Page Up 和 Page Down 垂直滚动。Escape 不会意外变成历史记录返回操作。

输入约定

地址栏使用原生 EDIT 控件。Enter 提交地址，Escape 恢复最近一次提交的地址。Backspace 仍然是 EDIT 控件的删除键。

原生文本控件

下面的文本框、密码框和多行文本框都是原生 WM6 EDIT 子窗口。它们的值、焦点以及 beforeinput/input/change 路径已经接入 Core 文档。




原生选择控件

单选和多选 SELECT 使用 WM6 的 COMBOBOX/LISTBOX 原生控件。选中状态会提交回 Core 文档，并接入 Browser 的 input/change 事件桥。



按钮、SIP/IME、文件选择和表单提交将在后续输入批次中接入。
