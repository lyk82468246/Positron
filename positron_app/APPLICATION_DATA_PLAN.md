# 设置、访问历史与下载的应用数据设计

## 边界与推进顺序

本设计描述应用数据的稳定合同，实际完成状态和证据由交接维护。访问历史、扩展设置、真实下载与
下载记录分别构建、自动设备验收和人工复核。当前设置实现及路径、
服务授权、退出所有权见 [接线计划](INTEGRATION_PLAN.md)。

应用拥有数据表、保留策略、可信页面业务方法、窗口、文件保存与任务调度；DB 拥有 SQL、
事务和迁移，Browser 拥有导航栈、页面提交与受控服务桥，HTTP 拥有流式传输与取消。
不得在 EXE 复制 URL、HTTP framing、导航提交资格或脚本队列语义。发现公共接口缺口时
停止该纵切并提交具体消费者场景与 DLL 提案，不顺手改 DLL 或放宽现有断言。

## 共用存储和迁移

继续使用 EXE 同目录的 positron.db、一个 DB 所有者 worker 和有界复制数据队列。
不为访问历史与下载再开启独立写库线程，不向网页暴露 SQL、数据库路径或文件句柄。
读取、写入、清除均为异步；COMMIT 后才确认持久化成功，页已关闭的已接受操作仍排空。

设置、访问记录、下载记录共享数据库、所有者 worker、固定操作队列和统一迁移序列，
不是混用一张万能表。访问和下载共享 ID、UTC、来源 URL 的约定；下载另有路径、临时路径、
最终 URL、状态、字节数和错误字段。共同的 Core 记录列表组件负责转义、标题/详情/时间布局与
选择性长文本断行；标题、来源、时间、状态分别为自然高度的块，不以行内换行符串接字段。
各列表保留独立查询、分页游标、清除权限和状态，不把导航栈混入这些表。

schema v3
保留 v1 的固定主页兼容行及 v2 访问记录，新增单例 `app_preferences`，一次保存
`startup_url`、`language`、`javascript_enabled`；升级从旧行复制主页，默认跟随系统、启用 JS。
旧固定主页接口仅更新 URL，保留另外两项；完整快照由 EXE 私有 SaveValues/结果 values
传递，不能用旧枚举读取网络主页或策略。设置页、主页菜单和启动均消费完整快照。
未知未来版本拒绝写入，失败保留文件，不删除、重建或静默改用 JSON。只通过公开 DB 接口
迁移，不读写 DLL metadata。v4 增加 `app_downloads`，不改写旧设置或访问表。
文件存储 worker 在打开/恢复前取得应用级所有者租约；同一路径的第二个应用 store 安全拒绝，
不能把另一个仍在下载的进程标成中断。该租约不替代 SQLite 的公共事务/跨进程锁。

## 第一纵切：持久访问历史

访问记录与每标签的 Browser Back/Forward 栈分离。首版仅记录成功提交的 HTTP(S) GET
文档，包括成功的刷新和跨文档回访；失败、取消、stale、尚未提交的候选、内部页和自检
不写入。片段滚动、push/replaceState 不制造额外访问条目。POST 的记录与重新访问策略另行
验收，不保存请求体、Cookie、认证 header 或 JS state。

记录复制公开接口给出的最终 URL、提交时标题、UTC 时间与递增记录 ID；不借用 DOM 或
Browser 字符串到 worker。标题缺失时显示 URL。写入与有界裁剪在同一事务完成；首版最多
保留 500 条，超额删除最旧记录。不依赖设备时钟排序，使用记录 ID 作为稳定分页游标。
URL 可能包含查询隐私，页面明确说明会本地保存，清除入口须确认；不把清除按钮写成物理
安全擦除保证，也不发送历史数据到网络。

positron://history 分开展示“访问历史”和“当前标签导航栈”。持久列表每页 16 条，
按最新在前展示，支持下一页、重新读取及确认清除；显示数据库不可用/读取失败，不把失败
伪装成空记录。清除只影响访问记录，不删除 DB、设置、下载文件或 Browser 导航栈。
点击记录按已支持 URL 发起新 GET 导航，不恢复过时的 DOM、history 索引或脚本状态。

历史页无脚本，分页、重读和确认清除由页内链接控件发起，右菜单保持固定；仅当前历史页面可执行，
不开放 URL 命令或网页服务。固定请求、结果和页面焦点容量，结果核对 tab/generation 与
请求 ID；离页迟到结果不更新新页，清除成功使所有标签缓存失效。动态标题和链接正确转义，
展示仍消费 Core 和原生控件接线。后续前后端服务扩展另行验收，不向普通网页授权。

验收包括 v1 迁移/保留主页、独立进程恢复、跨标签记录、成功/失败提交边界、裁剪与分页、
转义、清除不影响设置/导航栈、离页迟到结果、队列满和正常退出排空。自检不得污染用户
访问记录，真实故障注入仍按用户决定暂缓，正常重启不等于断电验收。

## 第二纵切：扩展设置

用户已确认首批字段为 HTTP(S) 主页、语言（跟随系统/英语/简体中文）及网页 JavaScript 开关，
在历史纵切后实施。URL 继续由公共解析/现有注册表检查，拒绝未支持协议和 quit；
不创建私有 URL 引擎。语言重启生效，不在已有窗口中混合资源；脚本开关作用于随后加载的
网页，不撤销正在执行的代码。可信设置/历史/下载页面的最小业务脚本与网页脚本策略分开。

设置变更必须原子保存，UI 展示实际保存结果；保存失败保留上次已提交策略。启动读取完成
前不得以默认值覆盖用户设置；显式启动地址优先，用户操作后不以迟到配置替换当前页面。
不同时扩展代理、证书豁免、任意脚本预算或自动恢复标签。验证旧数据默认值、重启后的
语言、禁用脚本的真实页面、可信页仍可保存、非法 URL、失败/容量与退出。

当前存储快照不超过 2048 字节 URL、三个固定语言值和严格布尔 JS 值，八请求预算不变；
HTTP(S) 规范化消费现有 URL 适配器，内部主页仅接受原三个地址，不接受 quit 或未知协议。
v1/v2 文件升级、跨进程完整恢复、旧写入保留策略、拒绝不入队、写入失败回滚及未来版本
拒绝由隔离 EXE 设备门验证。可信服务已支持完整快照：`settings.read` 返回
`startupPage`、`language`（`system/en-US/zh-CN`）和布尔 `javascriptEnabled`；`settings.write`
接受恰好这三个字段，旧单字段内部主页写入保留兼容。类型、未知字段、NUL、URL 和
转义后容量在入队前检查；请求/结果遵守 Browser 4096 字节预算，普通网页不获授权。
完整 JSON 经公共 JSON DLL 解析/序列化，字符串正确转义，结果仍由 COMMIT 后快照与
tab/generation/token 交付。URL 语法服从公共 HTTP 解析器；设置服务另要求完整 URL 少于
1024 UTF-8 字节，匹配现有 EXE 导航容量，不以存储容量绕过限制。
设置页使用原生文本输入、语言下拉与 JS 复选框，读取成功前禁止保存，原子写入成功后才
更新策略缓存。DOM 值及 disabled 变更通过 EXE 私有通知同步原生控件，不复制 Core 状态语义。
启动只激活一次空窗体，正常消息泵等待异步配置至多两秒；随后选定语言，再创建菜单、
控件和首个页面。无占位页面或迟到导航；读取失败/超时保留文件、显示不可用，网页 JS
先关闭。迟到成功结果只更新缓存，不抢前台、不切换资源或替换当前页。显式启动 URL 优先。
网页候选在接受时复制已提交 JS 策略；关闭时不获取外部脚本、不创建 session 或执行作者
脚本，CSS/图片仍按原事务处理。保存开关不改变已经接受的候选或现存 session，可信设置页
始终允许最小内嵌服务代码。语言只在下一次进程启动时应用。

## 第三纵切：真实下载与下载记录

首版从 downloads 内嵌文档的直接页内操作启动显式 HTTP(S) GET；不先实现通用网页
下载属性/Content-Disposition 默认动作，不在 EXE 私自定义这些可复用的 Browser 语义。
页面下载动作若需要新 DLL 能力，先停止并协调。保存路径由原生选择/用户确认，不把服务端
filename 或 URL 直接拼成文件路径，不自动执行下载文件或覆盖已有文件。
输入地址后先点“解析链接”。EXE 私有 `AppDownloadPrepare` 在 worker 中执行公开 Probe GET，
30 秒内取得最终响应头与名称合同后关闭请求，不等待 GUI、不创建文件或写入下载记录。
每标签拥有输入代际和结果副本，进程最多一个活动预检；修改 URL（包括改回原值）、离页、
新导航或关闭立即使旧结果失效并协作取消，join 后才查询/关闭请求。UI 非阻塞轮询，
取消或迟到结果不提供下载资格；不移交 live DOM 或复用已经关闭的网络连接。

应用首版只接受最终 HTTP 200、已知总量不超过 32 MiB。HTTP 拥有重定向、最终 URL、
Content-Disposition/URL basename 解析与错误分类；EXE 不再次解码名称，不补猜 index.html/bin。
成功显示最终 URL、类型和已知/未知大小，名称可编辑。缺名必须由用户填写并确认；服务端
名称非法、未支持或超限直接拒绝，不能用手工命名掩盖失败。EXE 另检查 UTF-8、255 字节预算、
WM6 保留名、路径分隔符、控制字符和尾点/空格。仅有效预检及合法名称才呈现“下载”动作；
错误或未解析状态不会打开保存框。原生保存框由已确认 basename/扩展名初始化，最终路径
以用户确认值为准；返回后再次核对标签、文档和输入代际，再验证最终文件名。
预检状态不持久化，不改变 v4 schema。失败分别展示 HTTP、网络/证书、取消、预算或名称原因。

最多两个任务、一个活动传输，其余排队；任务属于应用而非标签，切页不取消传输。
初始排队记录 COMMIT 后才调度，排队取消也持久化。网络 worker 只持有复制任务数据、HTTP request
和文件，不借用 live DOM/ScriptSession。使用公开 PHttp_Stream*，明确总超时和下载上限，
总期限为 120 秒、正文上限 32 MiB，按流式块写入目标同目录的 CREATE_NEW 临时文件，
不累积完整响应体。保留 TLS 链/hostname 校验。新 Stream GET 的最终头 callback 消费公开
`PHttp_ProbeMatchFinalHeaders`，复核预检副本的最终 URL、状态和元数据，变化或 HTTP 拒绝在
正文 sink 前停止；保留原始 CHANGED/HTTP_STATUS，不误称文件写入错误。两次 GET 不复用
socket，相同元数据不证明正文内容相同；此批不承诺字节身份或自动重试解析。
非 2xx、未请求的 206、传输失败、超限、
磁盘写入失败及取消均不发布最终文件；目标文件中途出现时也不覆盖。

成功顺序为完整传输、Flush/关闭文件、COMMIT 发布中状态、同卷 MoveFile 发布最终名称，
再 COMMIT 完成记录。DB 与文件系统不是一个原子事务；发布或记录失败不谎报成功。
进入已提交发布阶段后不再接受取消，关闭等待其终态。重启把遗留活动记录标为中断，
页面提示检查保留路径，不自动续传或删除用户文件；完成记录的文件不可访问时明确提示。
删除记录不删除文件，删除文件另需明确确认。

取消复用公开跨线程 Cancel，等待 Get 返回及 worker 结束后才 Close；退出先取消并 join
全部预检，再协作取消活动任务、收敛排队任务，最后停止共享 store 接收并排空 DB，
不 TerminateThread。预检可与一个已确认传输共存，活动网络上限为一个预检加一个下载。
只清理当前任务自己 CREATE_NEW 的临时文件，删除失败保留路径；不清理启动残留。
进度是有界 POD 快照，下载页至多一秒更新一次变化文字，拖动期间延后更新；
列表快照刷新保留输入，原生 EDIT 聚焦期间不重建页面。未知总长度不伪造百分比。
结束记录最多 500 条、每页 16 条；页内重读/较早/确认清除与历史使用相同列表布局，
清除只删结束记录，不删文件、设置或访问记录，不增加右软键项目。
传输完成不等于文件已保存，更不等于 DB 记录已经持久化。

验收包括缺名/手工确认、非法名称、预检 HTTP 拒绝、输入改回仍失效、取消/关闭 join、
真实输入框的异步响应和最终头变化零正文拒收，再使用超过 1 MiB 的文件、重定向、
non-2xx、取消、写入/发布拒绝、
退出与重启收敛，再验收真实 HTTPS、原生保存对话框和触摸。Range/续传、认证 Cookie、
POST 下载、压缩、后台多进程与开机恢复任务不包含在首版。
